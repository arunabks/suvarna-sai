# Nirmal Kumar × Devi Suvarna — Bride-side Animated Invitation

Updated animation edition, based on the approved cinematic maroon-and-gold version.

## Viewing
- Open `index.html` in a browser; keep `styles.css`, `script.js`, and `assets/` together.
- Or open `Bride_Side_Animated_Standalone.html` as one standalone file, which includes the images and motion.

## Animated details
- gold petals and light motes float at the outer edges (never on text)
- softly swaying botanical vines and ornate corners
- cinematic portrait zoom, radiance and 3D arch breathing
- slow gold shimmer across the existing Telugu titles
- light scroll parallax for decorative layers and gallery photos
- automatic motion reduction for guests who request reduced animation

All existing Telugu copy, parent names (without గారు in the family panel), dates, map link, and event location remain as in the previous bride-side version. The selected wedding music is tap-to-play because browsers restrict autoplay.

Telugu font: ANU Unicode webfont support is included as a slot, with Noto Serif Telugu as current public fallback. Provide a licensed Unicode-compatible ANU .woff2 to enable it.

Website is not published; upload the folder to a static host, or use the standalone HTML file.


### Visible Telugu name fix (2026-10-10)
The opening names `దేవి సువర్ణ` and `నిర్మల్ కుమార్` now use a permanently visible gold text fill and understated embossed light effects, avoiding transparent gradient clipping on certain browsers. All other invitation content and animations remain the same.
