TELUGU FONT SUPPORT
The website prioritizes locally installed ANU Telugu fonts where available, then safely falls back to the Unicode font Noto Serif Telugu (Google Fonts).
If you own a licensed, Unicode-compatible ANU webfont, place it in this folder named anu-unicode.woff2. Do not use a legacy non-Unicode ANU TTF directly with Telugu Unicode text without conversion.
No commercial font files are included in this package.
